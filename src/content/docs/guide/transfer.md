## 为什么要做成事务 {#why}

把文件拷到机床上，看起来是一个动作，实际上至少是三个：删掉旧的、写入新的、确认写对了。
中间任何一步断掉，机床就停在一个**没人知道是什么状态**的中间态。

DNC Pro 把这三件事包成一个事务：**要么机床上是新版本且经过校验，
要么机床上还是原来那个程序。没有第三种结果。**

## 六个阶段 {#stages}

```text
 ①预检 ──► ②快照 ──► ③删除 ──► ④发送 ──► ⑤回读 ──► ⑥校验 ──► 成功
                        └──────────┴──────────┴─────── 失败 ──► 自动回滚快照
```

| 阶段 | 做什么 | 失败时 |
| --- | --- | --- |
| **① 预检** | 机床可达、程序号未被锁定、分配有效 | 机床**未被改动**，无需回滚 |
| **② 快照** | 读回机床上现有的内容，存为快照 | 机床**未被改动**，无需回滚 |
| **③ 删除** | 删除目标文件 | 明确未删除 → 无需回滚；结果不明 → **回滚** |
| **④ 发送** | 写入转换后的内容 | **回滚** |
| **⑤ 回读** | 把刚写进去的内容读回来 | **回滚** |
| **⑥ 校验** | 归一化后逐字节比对回读内容与发送内容 | **回滚**，并把这个文件标记为异常 |

**只有第 ⑥ 步通过，才写"成功（已校验）"。** 发送成功不算成功，回读成功也不算成功。

:::note[目标本来就是空的]
如果快照阶段发现机床上还没有这个文件，事务会记录"目标为空"，
失败时的回滚动作就是"把可能写进去的半截文件删掉"，而不是恢复一个不存在的旧版本。
:::

## 回滚的三种结果 {#restore}

| 回滚结果 | 含义 |
| --- | --- |
| **无需回滚** | 失败发生在机床被改动之前 |
| **已回滚** | 快照已成功写回，并经回读确认 |
| **回滚失败** | 快照写回也失败了——**这个文件被标记为异常，需要人到机边确认** |

"回滚失败"是唯一需要立刻有人去机床边看一眼的情况。
它会在设备页和机边操作台上持续显示，直到下一次成功的校验把它清掉。

## 读传输记录 {#read-log}

![传输记录](/img/console/deployments.png)

| 列 | 说明 |
| --- | --- |
| 机台 / 文件 | 发给谁、落地叫什么 |
| 状态 | 排队中 / 成功（已校验）/ 失败 |
| 失败阶段 | 卡在六个阶段的哪一个 |
| 回滚 | 无需回滚 / 已回滚 / 回滚失败 |
| 试制 | 这一次是不是[试切](/guide/trials/) |
| 排队时间 / 完成时间 | |

顶部可以按机台和状态筛选，右上角给出"共 N 条，M 进行中，K 失败"。
总览页的"24 小时内失败传输"直接链到这里的失败筛选。

## 失败之后怎么办 {#failure}

1. **先看失败阶段。** 预检/快照失败 = 机床没被碰过，安心排查网络或机床状态。
2. **再看回滚结果。** "已回滚"意味着机床上还是原来那版，生产可以继续。
3. **看失败详情。** 例如 `send failed: Network fault.`——这条信息直接来自网关。
4. **修复后重新下发。** 下发是幂等的，重来一次即可。

常见失败原因见[常见问题](/faq/#transfer-fails)。

## 归一化比对 {#normalization}

第 ⑥ 步的比对不是简单的字节相等——不同控制器在存取时会做一些无害的变换：

- 行结束符可能被统一
- FANUC 的 O 号前导零可能被去掉
- 末尾空行可能被增删

DNC Pro 按目标机床的**厂商画像**做归一化后再比对，
避免把"控制器的正常行为"误报成"内容不一致"。
真正的内容差异（哪怕只差一个字符）一定会被抓到。

## 并发与让路 {#concurrency}

- 同一台机床同一时刻只执行一个传输任务
- [滚动镜像](/guide/mirror/)**永远给真实传输让路**——每一次网关调用之间都会检查
- 镜像跳过机床**当前正在运行的程序**

所以下发不会因为后台备份而变慢或被打断。

## 权限 {#permissions}

| 动作 | 需要 |
| --- | --- |
| 下发已发布版本 | `deployments.send.released`（操作工/编程员/管理员） |
| 下发试制版本 | `deployments.send.proveout`（编程员/管理员） |

授权范围可以按**机组**限定——操作工只能对自己机组的机床下发。
