## v1.0.0 {#v1-0-0}

首个正式版本。

**产品能力**

- **程序库**：程序库 / 程序 / 版本三层结构，版本生命周期（草稿 → 待审批 → 已发布 → 废弃），
  内容哈希去重，任意两版并排比对，变体分组
- **审批**：程序库级策略（审批人数、禁止自审自批、自动放行），审批队列与差异评审
- **设备**：多网关注册与机台同步，机组与试切策略，严格模式
- **机台分配**：程序名改写、`%` 包裹、行结束符、目标编码四项落地转换，转换预览
- **事务式下发**：预检 → 快照 → 删除 → 发送 → 回读 → 校验六阶段管线，
  失败自动回滚快照，归一化比对
- **试制**：限时试切、全界面徽标、到期不自动处理、机组级禁止试切
- **滚动镜像**：全天候备份机床上的每一个文件，给真实传输让路，跳过运行中的程序，
  镜像失败记录到机床上
- **机边修改**：受管文件的机床侧改动自动捕获成待处置版本，采纳 / 拒绝（可选推回），
  绝不自动还原
- **未受管文件**：完整备份与快照还原，一键采纳进程序库
- **权限**：五个固定角色 × 三种授权范围，本地账号与可选 OIDC，服务令牌与代理身份
- **审计**：只增不改的哈希链日志，状态变更与内容外流分类，查询 / CSV 导出 / 链完整性校验
- **集成**：五类事件的签名 Webhook 与重试，完整的 OpenAPI 3.1 文档与交互式参考
- **两个前端**：管理控制台与机边操作台，均为同一套 REST API 的客户端，支持中英文切换
- **运维**：`/healthz` 存活探针与 `/readyz` 就绪探针（含 blob 存储可写性），
  定时备份与保留策略，启动时自动迁移

**手册**

- 首次发布，覆盖概述、快速上手、日常使用、参考与常见问题
- 全部界面截图取自可复现的演示数据集
